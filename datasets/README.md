# Exported CODE-ACCORD datasets

This export contains the three derived datasets used by the CODE-ACCORD
experiments:

| Directory | Records | Used by |
|---|---:|---|
| `codeAccordValueExtraction/` | 292 | `exp_074` |
| `codeAccordValueExtractionContext5Lines/` | 290 | `exp_076`, `exp_080`, `exp_081` |
| `codeAccordValueExtractionFullPdf/` | 292 | `exp_079`, `exp_084`, `exp_085`, `exp_089` |

The corpus is CODE-ACCORD, created by Hettiarachchi et al. The upstream
CODE-ACCORD v1.0.0 Zenodo record (DOI
[10.5281/zenodo.10210022](https://doi.org/10.5281/zenodo.10210022)) specifies
the [Creative Commons Attribution 4.0 International license](https://creativecommons.org/licenses/by/4.0/).
Please retain attribution to the CODE-ACCORD authors and cite:

> Hettiarachchi, H. et al. (2025). CODE-ACCORD: A Corpus of Building Regulatory
> Data for Rule Generation towards Automatic Compliance Checking. *Scientific
> Data*, 12, 170. <https://doi.org/10.1038/s41597-024-04320-x>

The exported data are derivatives: the base set selects annotated value spans
and creates value questions; the context set adds up to five surrounding
sentences; the full-PDF set replaces the input content with extracted source
PDF text and records source-match status. The exact upstream Hugging Face
revision used to create the checked-in base set was not recorded. Source
mapping qualifications for the context and full-PDF variants are documented
in the upstream project notes and record metadata.

The JSON files are exported data artifacts, not regenerated by this repository.
`../results/codeaccord/` contains the corresponding run records, linked by
`source_example_id`, `source_split`, `value_span_index`, and dataset filename.
