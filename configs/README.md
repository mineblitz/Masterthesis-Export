# Exported experiment configurations

These are the original JSON configurations for the CODE-ACCORD experiments
whose results and datasets are exported here:

- `exp_074`: sentence-level value extraction
- `exp_076`: sentence-context direct question answering
- `exp_079`: full-PDF-text direct question answering
- `exp_080` and `exp_081`: v8 and v36 on the shared context dataset
- `exp_084` and `exp_085`: v8 and v36 on full-PDF text
- `exp_089`: the v17 full-document model screen

`exp_075` is intentionally omitted: despite its legacy display name, its
configuration uses the condition-based fire-protection dataset, not CODE-ACCORD.
The configuration JSONs preserve the original relative dataset paths and
experiment identifiers.
